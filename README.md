# ⏳ Loading Page

Projeto de **Loading Page** desenvolvido utilizando apenas **HTML e CSS**, com foco em animações de carregamento modernas e suaves.
A página apresenta um loader animado que pode ser utilizado em sites, sistemas ou aplicações enquanto o conteúdo principal é carregado.



## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Animações com CSS
* Keyframes
* Flexbox


---

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para praticar:

* Animações com CSS
* Centralização com Flexbox
* Criação de loaders
* Estruturação com HTML
* Boas práticas de CSS
